Audiobus Remote
Connect to a computer

Share this computer

Run the Audiobus agent on the computer you want to let someone control. It generates a fresh 10-character code every time it starts.

⬇ Download the agent (Windows)
  1. Download and run the agent (audiobus-agent.exe). A window opens.
  2. It shows a session code, for example 7K4M9QW2AB.
  3. Give that code to the person who will connect.
  4. When they connect, the agent asks you to approve. Only after you approve does your screen start streaming.
  5. Close the agent window at any time to end the session instantly.
Don't have the executable yet? If the download above returns "not found", the binary hasn't been built and published yet. You can run the agent from source in the meantime: 
cd agent
python -m pip install -r requirements.txt
python audiobus_agent.py
Building the standalone .exe is covered in the project README (agent/build.ps1).
This is a remote-control tool. Only run the agent on a computer you own or are authorized to share, and only give the code to someone you trust. Anyone with the current code (and your approval) can control this computer until you close the agent.
